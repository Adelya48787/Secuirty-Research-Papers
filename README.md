## 📄 Research Reports

The research reports are stored in separate branches to keep the `main` branch clean.

| Research | Branch |
|----------|--------|
| Laravel Lang Compromise | `Laravel-Lang-Compromise` |

### How to access a report

1. Click the **Branch selector** (currently showing `main`).
2. Select **`Laravel-Lang-Compromise`**.
3. Open the **README.md** in that branch.

Or switch using Git:

```bash
git fetch origin
git checkout Laravel-Lang-Compromise
```
