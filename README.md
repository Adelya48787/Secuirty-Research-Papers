| Research | Branch |

| Postfix SMTP Smuggling | `Postfix-SMTP-Smuggling` |

### How to access a report

1. Click the **Branch selector** (currently showing `main`).
2. Select **`Laravel-Lang-Compromise`**. (As an example, you may opt any branch to imerse in the analysis)
3. Open the **README.md** in that branch.

Or switch using Git:

```bash
git fetch origin
git checkout Laravel-Lang-Compromise
```
